# SIMMETRIKA: сайт интернет-магазина диванов (превью)

Превью: https://takedown-desing.github.io/simmetrika-site/ (закрыто от индексации, заявки не уходят менеджеру).

Дизайн по референсу из папки `дизайн/` проекта (главная divanchik.ru): раскладка, типографика Roboto, красные кнопки-пилюли, серые подложки товаров, цветные плашки разделов, тёмный блок и подвал. Логотип, фото и тексты референса не использованы. Токены и компоненты описаны в [DESIGN.md](DESIGN.md).

Исследование, структуры страниц, тексты и вопросы к заказчику лежат в репозитории проекта: https://github.com/takedown-desing/simmetrika-prototype

## Что внутри

| Путь | Что это |
|---|---|
| `content/*.md` | Тексты 66 страниц (копия `drafts/content` проекта): YAML-шапка с meta и FAQ + markdown с директивами |
| `src/data/catalog.json` | Данные каталога: 19 товаров, ткани, наличие, образцы, шоурумы, настройки доставки |
| `src/data/images.json`, `public/img/p/` | Фото клиента в WebP 600/1200 |
| `src/lib/md.mjs` | Markdown → HTML: директивы `:::products`, `:::filters`, `:::tiles`, `:::steps`, `:::compare`, `:::scheme`, `:::form` и др. |
| `src/lib/render.mjs` | Карточка товара, плашки разделов, шоурумы, сватчи, таблицы, формы, схемы |
| `src/lib/schema.mjs` | JSON-LD @graph: Organization+FurnitureStore, WebSite, тип страницы, BreadcrumbList, Product+AggregateOffer, 5 × FurnitureStore, FAQPage |
| `src/pages/index.astro` | Главная по раскладке референса |
| `src/pages/[...slug].astro` | Все остальные страницы: категории, подборки, товары, заявка, сервисные |
| `public/js/app.js` | Заявка в localStorage, счётчик в шапке, фильтры и сортировка, выбор ткани/цвета/стороны с пересчётом цены, галерея, формы с маской телефона, «в один клик», обратный звонок |
| `scripts/` | `sync-content` (тексты и данные из проекта), `build-images` (WebP), `check-content`, `qa-dist` (H1, meta, JSON-LD, FAQ = FAQPage, ссылки, картинки) |
| `qa-report.md` | Последний QA-отчёт: 62 страницы, 0 критичных |

## Команды

```bash
npm ci
npm run sync      # подтянуть тексты и catalog.json из ../drafts
npm run images    # сделать WebP из ../source/photos
npm run build && npm run qa
```

## Ограничения превью

- Заявки сохраняются только в браузере (нет бэкенда): номер заявки и экран «спасибо» работают, письмо менеджеру не уходит. Бэкенд, админка, email и CRM по ТЗ делаются на выбранной платформе.
- Цены, сроки, тарифы, ткани и гарантия — рабочие допущения до ответов клиента (`QUESTIONS.md` в репозитории проекта).
- Фото стоят как есть. Задача «одинаковый фон у всех фото» требует обтравки и делается отдельно.
- Карта шоурумов схематичная, точные адреса открываются в Яндекс.Картах.
